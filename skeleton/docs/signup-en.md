# Create an account

## Purpose

Demonstrate an account creation form using email, an example password and acknowledgement that this is a demo.

## Expected behaviour

Validate required inputs, email format, an eight-character minimum password and the demo checkbox. Successful submission opens /dashboard. No account is created.

## Prototype boundary

All data and sessions are local examples. No backend, email delivery or persistent account is implied. Adapt this specification to your own requirements.
