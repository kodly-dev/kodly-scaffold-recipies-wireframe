# Working with wireframes

Open the Requirements project in Kodly Wireframe Studio. Sandpack renders the React files directly.
No separate application server, package installation or health check is needed.

- `App.js` is the entry point for the embedded React preview.
- Register screens in `route.js`. Each route points to a component in `screens/`.
- Put reusable UI in `components/` and use the semantic theme variables in `styles.css`.
- Keep screen-specific documentation in `docs/` and optional translations in `locales/`.
- Use labelled example data, real navigation and keyboard-accessible controls.
- Respect system appearance, reduced-motion preferences and narrow viewports.

The project overview is an example, not connected application data. Adapt it to the agreed requirements.
