# Overview

## Purpose

Help users find and review items. The sample list has a name and status, a search field, summary counts and an item detail area.

## Expected behaviour

Search filters names. Add item creates an in-memory draft. View opens details; Mark ready changes its status. An empty result explains how to recover.

## Prototype boundary

All data and sessions are local examples. No backend, email delivery or persistent account is implied. Adapt this specification to your own requirements.
