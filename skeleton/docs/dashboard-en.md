# Dashboard

## Purpose

Show the signed-in variant of the sample overview. This is a starting point for the project’s own authenticated screens.

## Expected behaviour

Without an example session, show a sign-in link. After login or signup, show the overview and a sign-out action. Signing out returns to /login.

## Prototype boundary

All data and sessions are local examples. No backend, email delivery or persistent account is implied. Adapt this specification to your own requirements.
